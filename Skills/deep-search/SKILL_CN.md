# deep-search（深度检索）

## 概述

本技能提供一套高级多轮检索方法论，用于全面的文献发现。当单轮标准检索不足以覆盖研究主题时使用。

## 操作指引

### 1. 初始广度检索

使用研究主题的核心关键词执行 2-3 个宽泛查询：
- 从 `Planning/task_breakdown.json` 中获取领域专业术语
- 同时使用中英文关键词，确保双语覆盖
- 通过添加年份限定（如 "2024"、"2025"）定位最新发表的成果

### 2. 滚雪球检索（引用追踪）

从初始结果中识别：
- **关键作者**：检索其近期的其他发表成果
- **关键术语**：提取原始查询中未包含的新术语
- **关键引用**：检索被频繁引用的基础性工作

基于以上发现构造 2-3 个新的查询。

### 3. 空白分析检索

在前两轮之后，识别尚未覆盖的领域：
- 将已收集的主题与研究计划的各维度进行对比
- 针对缺失的视角构造定向查询
- 检索对该主题的反面观点或批判性评论

### 4. 质量筛选

对每条结果评估质量：
- **高质量**：顶级期刊/会议（Nature、Science、ICML、NeurIPS 等），引用量 >100
- **中等质量**：知名预印本平台（arXiv）、成熟的技术博客，引用量 >10
- **低质量**：未经验证的观点、过时的资料（>5 年且无近期引用）

优先保留高质量和中等质量来源。低质量来源仅在覆盖独特视角时纳入。

### 5. 输出

按照 Survey Agent 系统提示中定义的标准输出格式保存所有结果。
